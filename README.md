# Проект виджетов
## Описание
Проект по разработке виджетов банковского приложения на Python для удобства пользователя.

## Функции проекта
В проекте представлены функции:
* Функция принимает на вход номер карты и возвращает её маску.
```python
get_mask_card_number("7000792289606361")
#Возвращает: 7000 79** **** 6361
```
* Функция принимает на вход номер счета  и возвращает его маску.
```python
get_mask_account("73654108430135874305")
#Возвращает: **4305
```
* Функция, которая маскирует информацию о картах и счетах
```python
mask_account_card("Visa Platinum 7000792289606361")
#Возвращает: Visa Platinum 7000 79** **** 6361

mask_account_card("Счет 73654108430135874305")
#Возвращает: Счет **4305
```
* Функция преобразования даты
```python
get_date("2024-03-11T02:26:18.671407")
#Возвращает: "11.03.2024"
```

    Функция возвращает новый список словарей, содержащий только те словари, у которых ключ
    state соответствует указанному значению.

```
[{'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'}, {'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'}]
```
* Функция, которая принимает список словарей и необязательный параметр, задающий порядок сортировки.
    Функция возвращает новый список, отсортированный по дате.
```
# Выход функции (сортировка по убыванию, т. е. сначала самые последние операции)
[{'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'}, {'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'}, {'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'}, {'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'}]

```
* Функция принимает на вход путь до JSON-файла
    и возвращает список словарей с данными о финансовых транзакциях.
* Функция для считывания финансовых операций из CSV-файла.
* Функция для считывания финансовых операций из XLSX-файла.

## Декораторы функций
### Декоратор @log
-Декоратор для логирования работы функций - записи в консоль или файл информации о вызовах функций, их результатах и ошибках.
### Назначение
- Логирование успешных выполнений функций
- Отслеживание ошибок и исключений
- Запись входных параметров функций
- Поддержка вывода в консоль или файл

###  Использование

#### Простое логирование в консоль
```python
from src.decorators import log

@log()
def my_function(a, b):
    return a + b

my_function(2, 3)  # Вывод: my_function ок. Результат: 5
```
Логирование в файл
```python
from src.decorators import log

@log(filename="test_log.txt")
def process_data(data):
    return data.upper()

process_data("hello")
```
### Особенности работы

    Сохранение метаданных: Использует @wraps для сохранения имени и документации оригинальной функции

    Безопасная работа с файлами: Автоматическое закрытие файлов при записи

    Обработка ошибок: Перехватывает все исключения и логирует их без прерывания работы программы

    Гибкий вывод: Поддержка как консольного вывода, так записи в файл




## Тестирование

### Для каждой функции в проекте написаны тесты

* Все тесты находятся в директории tests/
* Файлы тестов именуются как test_*.py
* Тестовые функции начинаются с test_
 
### Запуск тестов
```python
poetry run pytest tests/ -v  # Все тесты
poetry run pytest tests/test_dates.py -v  # Конкретный файл
```

### Покрытие тестами
```python
poetry run pytest --cov=src --cov-report=html
```
Отчет будет доступен в htmlcov/index.html

### Пример теста
```python
from src.masks import get_mask_account, get_mask_card_number


def test_get_mask_card_number() -> None:
    assert get_mask_card_number("7000792289606361") == "7000 79** **** 6361"


def test_empty_string_card_number() -> None:
    """Пустая строка возвращает строку с пробелами и звёздочками."""
    assert get_mask_card_number("") == " ** **** "
```

### Для тестирования функций с декоратором @log используйте:
bash

pytest tests/test_decorators.py -v


Тесты покрывают:

    Логирование успешных выполнений

    Обработку ошибок и исключений

    Запись в файл и вывод в консоль

    Корректность метаданных функций
