# Проект виджетов
## Описание
Проект по разработке виджетов банковского приложения на Python для удобства пользователя.
## Установка
1. Клонируйте репозиторий:
```
[Репозиторий](https://github.com/yulechka944992/homework.git)
```
2. Установите зависимости:
```
poetry install
```
3. Подключите виртуальное окружение
```
poetry shell
```
4. Проверьте качество кода:
```
poetry run flake8
poetry run black --check
poetry run mypy src/
```
## Функции проекта
В проекте представлены функции:
* Функция принимает на вход номер карты и возвращает её маску.
```python
get_mask_card_number("7000792289606361")
#Возвращает: 7000 79** **** 6361
```
* Функция принимает на вход номер счета  и возвращает его маску.
```python
get_mask_account("73654108430135874305")
#Возвращает: **4305
```
* Функция, которая маскирует информацию о картах и счетах
```python
mask_account_card("Visa Platinum 7000792289606361")
#Возвращает: Visa Platinum 7000 79** **** 6361

mask_account_card("Счет 73654108430135874305")
#Возвращает: Счет **4305
```
* Функция преобразования даты
```python

#Возвращает: "11.03.2024"
```

    Функция возвращает новый список словарей, содержащий только те словари, у которых ключ

## Тестирование

### Для каждой функции в проекте написаны тесты

* Все тесты находятся в директории tests/
* Файлы тестов именуются как test_*.py
* Тестовые функции начинаются с test_
 
### Запуск тестов
```python
poetry run pytest tests/ -v  # Все тесты
poetry run pytest tests/test_dates.py -v  # Конкретный файл
```

### Покрытие тестами
```python
poetry run pytest --cov=src --cov-report=html
```
Отчет будет доступен в htmlcov/index.html

### Пример теста
```python
from src.masks import get_mask_account, get_mask_card_number


def test_get_mask_card_number() -> None:
    assert get_mask_card_number("7000792289606361") == "7000 79** **** 6361"


def test_empty_string_card_number() -> None:
    """Пустая строка возвращает строку с пробелами и звёздочками."""
    assert get_mask_card_number("") == " ** **** "
```
